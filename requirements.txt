# Lillypad — fully pinned lockfile (Python 3.13)
#
# Install with --no-deps:
#
#     pip install --no-deps -r requirements.txt
#
# The --no-deps is REQUIRED, not an optimisation. pylablib hard-declares
# `pyqt5` as a dependency even though Lillypad uses PySide6 and only ever
# touches pylablib's device layer. A plain `pip install -r` re-installs
# PyQt5, putting two Qt bindings in the environment — which has broken
# PyInstaller builds here before. Every transitive dependency is pinned
# below, so --no-deps resolves to exactly this set.
#
# `pip check` will report "pylablib requires pyqt5, which is not installed".
# That warning is expected and correct to ignore: pylablib.gui needs PyQt5,
# pylablib.devices (all we import) does not.
#
# PyInstaller is additionally told to exclude PyQt5 in Lillypad.spec.
#
# NOT listed here: the Avantes AvaSpec DLL. avantes.py drives it through ctypes
# (stdlib), and the DLL itself comes from the vendor's AvaSpec-DLL package —
# an external installer, not a pip package. See the Avantes section of the
# README for what to install and where it lands.
